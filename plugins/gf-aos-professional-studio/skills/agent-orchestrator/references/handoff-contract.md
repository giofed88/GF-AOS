# Contratto di handoff Markdown

Ogni agente restituisce soltanto il risultato necessario al coordinatore.

```markdown
## HANDOFF <RUOLO>

- Case ID:
- Modulo / ruolo professionale:
- Obiettivo ricevuto:
- Perimetro esaminato:
- Stato: COMPLETED | PARTIAL | BLOCKED

### Risultati
- [FATTO | CALCOLO | INFERENZA | VALUTAZIONE DA VALIDARE] ...

### Evidenze e fonti
- locator — proposizione supportata — data/versione

### Limiti e contraddizioni
- ...

### Prossima azione consentita
- ...
```

Non includere catene di ragionamento, trascrizioni integrali, informazioni non pertinenti o dati
personali superflui. Se l'incarico e multidisciplinare, produrre un handoff per workstream.
