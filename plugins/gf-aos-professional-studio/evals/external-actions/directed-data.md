# Eval — Dati necessari in azione diretta

- Un report `external-draft` con identificativi produce `DATA_REVIEW_REQUIRED`.
- L'approvazione dell'azione senza nota dati e `APPROVO DATI NECESSARI` viene respinta.
- Segreti e prompt injection non sono mai derogabili.
- Registro e console non riproducono payload, destinatario reale o valori rilevati.
- L'alias del target non puo essere un indirizzo email.
