# GF-AOS Professional Studio

Plugin Codex per i flussi professionali dello studio di Giovanni Federico.

Il codice installabile si trova in [`plugins/gf-aos-professional-studio`](plugins/gf-aos-professional-studio). La cronologia conserva le versioni dalla v0.3.0. Seguono Document Intelligence, Agent Core, Lifecycle & Quality Engine, Professional Workflow Packs, Context Curation, Governed Learning, Privacy-first Automation Guard, Governed External Action Queue, Governed Remote Dossier Bridge per Google Drive, OneDrive e SharePoint, Governed Deadline and Reminder Engine, Governed Studio Dashboard, ECC Runtime Completion, design system documentale e, con la v0.17.0, workflow eseguibili per revisione legale, collegio sindacale e sindaco-revisore. Il progetto non contiene dati di clienti né credenziali.

Le skill guidano il lavoro professionale; gli script locali producono inventario, estrazioni, checkpoint, scadenze, task e controlli di qualita. Il ponte Drive, il motore reminder e il cruscotto preparano viste e richieste governate ma non incorporano connettori o scheduler live. Gli invii automatici richiedono integrazioni separate.
