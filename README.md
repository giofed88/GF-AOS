# GF-AOS Professional Studio

Plugin Codex per i flussi professionali dello studio di Giovanni Federico.

Il codice installabile si trova in [`plugins/gf-aos-professional-studio`](plugins/gf-aos-professional-studio). La cronologia conserva le versioni dalla v0.3.0. Seguono Document Intelligence, Agent Core, Lifecycle & Quality Engine, Professional Workflow Packs, Context Curation, Governed Learning, Privacy-first Automation Guard e, con la v0.11.0, Governed External Action Queue. Il progetto non contiene dati di clienti né credenziali.

Le skill guidano il lavoro professionale; gli script locali producono inventario, estrazioni, checkpoint e controlli di qualita. Dashboard, collegamenti Drive, invio Telegram e pianificazione automatica richiedono integrazioni separate.
