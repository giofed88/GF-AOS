# GF-AOS Professional Studio

Plugin Codex per i flussi professionali dello studio di Giovanni Federico.

Il codice installabile si trova in [`plugins/gf-aos-professional-studio`](plugins/gf-aos-professional-studio). La cronologia dei commit conserva le versioni successive. La v0.3.0 è la prima versione pubblicata; la v0.4.0 introduce Document Intelligence locale, la v0.5.0 l'Agent Core e la v0.6.0 il Lifecycle & Quality Engine. Il progetto non contiene dati di clienti né credenziali.

Le skill guidano il lavoro professionale; gli script locali producono inventario, estrazioni, checkpoint e controlli di qualita. Dashboard, collegamenti Drive, invio Telegram e pianificazione automatica richiedono integrazioni separate.
