# GF-AOS Professional Studio

Plugin Codex per i flussi professionali dello studio di Giovanni Federico.

Il codice installabile si trova in [`plugins/gf-aos-professional-studio`](plugins/gf-aos-professional-studio). La cronologia dei commit conserva le versioni successive. La v0.3.0 è la prima versione pubblicata; seguono Document Intelligence, Agent Core, Lifecycle & Quality Engine, Professional Workflow Packs e, con la v0.8.0, Context Curation & Confidentiality Guard. Il progetto non contiene dati di clienti né credenziali.

Le skill guidano il lavoro professionale; gli script locali producono inventario, estrazioni, checkpoint e controlli di qualita. Dashboard, collegamenti Drive, invio Telegram e pianificazione automatica richiedono integrazioni separate.
