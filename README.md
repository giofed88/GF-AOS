# GF-AOS Professional Studio

Plugin Codex per i flussi professionali dello studio di Giovanni Federico.

Il codice installabile si trova in [`plugins/gf-aos-professional-studio`](plugins/gf-aos-professional-studio). La cronologia dei commit conserva le versioni successive. La v0.3.0 è la prima versione pubblicata in questa repository; non contiene dati di clienti né credenziali.

Le skill guidano il lavoro professionale e lo script `inventory.py` produce un inventario locale di metadati. Dashboard, collegamenti Drive, invio Telegram e pianificazione automatica richiedono integrazioni separate.
